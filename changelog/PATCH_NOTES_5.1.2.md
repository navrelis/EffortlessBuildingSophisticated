# Sophisticated Building Update – 5.1.2 - Minecraft 26.2

A version alignment release for 26.2: there is no code change in this jar set compared with 5.1.0, only the version number, so that all files of the mod share 5.1.2. Nothing to migrate: worlds and configs of 5.1.0 load unchanged. Client and server compatibility is unchanged: the same-version rule from 5.1.0 still applies, and 5.1.0 and 5.1.2 jars of this branch can be mixed, since nothing network-related changed.

## Artifacts

* `sophisticatedbuilding-fabric-26.2-5.1.2.jar` — Fabric
* `sophisticatedbuilding-neoforge-26.2-5.1.2.jar` — NeoForge
* `sophisticatedbuilding-forge-26.2-5.1.2.jar` — Forge

## Requirements

Unchanged from 5.0.2 (see `PATCH_NOTES_5.0.2.md`).
