# Sophisticated Building Update – 5.1.2 - Minecraft 1.18.2

A version alignment release for 1.18.2: there is no code change in this jar set compared with 5.1.0, only the version number, so that all files of the mod share 5.1.2. Nothing to migrate: worlds and configs of 5.1.0 load unchanged. Client and server compatibility is unchanged: the same-version rule from 5.1.0 still applies, and 5.1.0 and 5.1.2 jars of this branch can be mixed, since nothing network-related changed.

## Artifacts

* `sophisticatedbuilding-fabric-1.18.2-5.1.2.jar` — Fabric, Minecraft 1.18.2
* `sophisticatedbuilding-forge-1.18.2-5.1.2.jar` — Forge, Minecraft 1.18.2

## Requirements

Unchanged from 5.0.1 (see `PATCH_NOTES_5.0.1.md`).
