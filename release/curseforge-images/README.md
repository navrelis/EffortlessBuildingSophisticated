# CurseForge images for the 5.0.0 description

Screenshots from the in-game smoke runs (Minecraft 1.21.1; 01 and 03 from Fabric, the rest from NeoForge), 854x480,
each under 250 KB. `release/curseforge-description.md` has a placeholder line where each image belongs, in the form
`![Alt text](IMAGE: <file>)`.

| `02-line-preview.png` | A line being built: white outline, ghost blocks, `5 blocks (5x1x1)`, click hints, `5x Stone` cost list | 2. Getting started > Placing | **Live preview** - See every block, the block count and size, and the materials before you place. |

After uploading the images to the project's gallery (or as description images) on CurseForge, copy each image's URL
and replace the placeholder: `![Radial menu](IMAGE: 01-radial-menu.png)` becomes `![Radial menu](https://media.forgecdn.net/...)`.
A quick search for `IMAGE:` in the description finds every placeholder (there are 10).
